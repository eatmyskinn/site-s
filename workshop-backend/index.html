Запись в автомастерскую

Услуги, заявки и личный кабинет. Клиент предлагает время, администратор подтверждает визит. Приложение на Django с REST API, HTML-формами и базой данных.

Что внутри

Заявки и доступ

Вход по сессии или API-токену. Пользователь видит и отменяет только свои заявки.

База данных

Django ORM, миграции, связи пользователей и услуг. PostgreSQL или SQLite для локального запуска.

Проверки

Валидация данных, защита от повторных заявок, тесты API и форм. GitHub Actions для SQLite и PostgreSQL.

Как посмотреть приложение

Скачайте репозиторий и следуйте README в папке workshop-backend. GitHub Pages показывает эту страницу описания; для Django нужен Python-сервер. Проект не подключён к реальной мастерской и не отправляет ей заявки.
