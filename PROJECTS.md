## Hausmeister Plus · WordPress · в разработке

[Открыть демоверсию](hausmeister-plus/) · [Исходники темы](hausmeister-plus/theme/)

Собственная тема WordPress, версии DE/RU, адаптивная вёрстка и поля для редактирования основных текстов и цен. Статическая демоверсия показывает дизайн; обработчик заявок находится в теме. Публикация, реальные контакты и доставка писем пока не завершены.


## Запись в автомастерскую · Django / REST API

[Код и запуск](workshop-backend/README.md). Учебное приложение: услуги, заявки пользователей, отмена, подтверждение администратором, REST API и страницы на Django templates. SQLite для быстрого запуска, PostgreSQL через переменные окружения. Тесты и GitHub Actions. К реальной мастерской не подключено.
