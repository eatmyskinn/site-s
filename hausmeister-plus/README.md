# Hausmeister Plus

Проект сайта бытовых услуг в Гамбурге и Нижней Саксонии. **Статус: в разработке.**

[Демо на немецком](index.html) · [Демо на русском](ru.html) · [Тема WordPress](theme/)

## Реализовано

- Индивидуальная тема WordPress на PHP, HTML и CSS, без платного конструктора.
- Немецкая и русская версии, переключатель языка.
- Адаптивные страницы с услугами, ценами, порядком работы и преимуществами.
- Настройки основных текстов, цен и контактов через WordPress Customizer.
- Серверный обработчик формы с одним фото JPG/PNG/WebP до 5 МБ, проверкой nonce, полей и ограничением частоты.
- Простой логотип H+ и авторская SVG-иллюстрация для первой версии.

## Что показывает демо

Здесь размещена статическая копия дизайна. WordPress и его админка на GitHub Pages не запускаются. Форма в демо выключена и ничего не отправляет.

Локальная версия работает в WordPress Playground. Доставка писем ещё не проверена: необходимы почта заказчика и настройка хостинга/SMTP. Контакты, реальные отзывы, фотографии, Impressum и Datenschutz предстоит получить и согласовать с заказчиком.

Демо не представлено как запущенный официальный сайт; оплата и окончательная приёмка проекта не заявляются. База данных, пользовательские документы, ключи и локальная среда WordPress в репозиторий не включены.
