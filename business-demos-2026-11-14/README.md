# Три сайта для локальных предприятий

Дата проверки: 14 ноября 2026. Самостоятельные статические HTML/CSS/JS страницы. Откройте index.html или разместите содержимое папки в GitHub Pages. Все изображения встроены в HTML как data:image/jpeg;base64 и работают при открытии локально и в подпапке репозитория. Google Fonts требуют интернета, предусмотрены системные запасные шрифты.
